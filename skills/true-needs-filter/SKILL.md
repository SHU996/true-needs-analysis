# True Needs Filter（真需求快速过滤）

> 来源框架：梁宁《真需求》（新星出版社，2024）
> 这是 true-needs-analysis 工具包的第一步——30秒快速判断。

## 核心原则

```
真需求 = 用户 + 场景 + 痛点
三者都必须具体、可观察，不能是推断
```

大多数产品失败不是因为做得不好，而是因为建立在了**想象的需求**上。这个skill只做一件事：**用最快的速度告诉你，这个需求是不是想象出来的。**

## 使用前提

**只在用户主动要求快速验证时运行本 skill。**
- ✓ "帮我快速判断这个想法靠不靠谱"
- ✓ "值不值得做"
- ✓ "这个需求是真的吗"
- ✗ 用户想要深度分析 → 建议使用 true-needs-deep
- ✗ 用户说"我想做 X"但意图是问怎么做 → 不要拦截，直接帮他做

## 运行流程

### 只做一件事：跑这三个选择题

以**选择题**形式向用户提问——用户只需选 A/B/C，**不需要打字描述**。三个问题一次性展示：

---

**Q1. 你的用户是谁？**

- **A)** 我能说出一个具体的人——知道他/她叫什么、做什么、每天什么环节最头疼
- **B)** 大概知道是哪类人，但说不出具体个体
- **C)** 只能描述"某类用户"，比如"忙碌的上班族"

**Q2. 你从哪些渠道了解到这个痛点？（可多选）**

- **A)** 亲眼观察到过——看到过帖子、投诉、吐槽，或有真实的行为记录
- **B)** 听别人提过，但没具体记录
- **C)** 自己就是用户，亲身经历过
- **D)** 逻辑推断"应该有这个问题"

**Q3. 你观察到用户目前是怎么处理的？（可多选）**

- **A)** 有人花钱或买工具凑合解决
- **B)** 有人花大量时间手工处理（Excel/人工核对等）
- **C)** 没人在解决这个问题，不确定痛点够不够强
- **D)** 没调查过

---

### 评估规则

用户回答后，根据以下条件判断（Q2、Q3 为多选，只要含对应选项即满足）：

| 条件 | 结论 | 下一步建议 |
|---------|------|-----------|
| Q1选A + Q2含A或C + Q3含A或B | ✅ 通过快速过滤 | 三要素都有实据，可以继续推进 |
| 有 1-2 个不满足 | ⚠️ 存在风险 | 指出具体哪个问题需要调查，建议补齐后再推进 |
| 三个都不满足 | 🛑 想象中的需求 | 建议先去现场观察，收集真实证据后再回来 |

## 输出格式

给出评估后，输出以下格式的结论（简洁，不超过150字）：

```
## 快速过滤结论

**判断：** ✅ 可以推进 / ⚠️ 需要先调查 / 🛑 暂停，重新调研

**三问结果：**
- 用户：[具体 / 模糊 / 缺失]
- 痛点来源：[观察到 / 听说 / 亲历 / 推断]（多选）
- 绕路行为：[花钱凑合 / 手工处理 / 无人解决 / 未调查]（多选）

**最关键的风险：** [一句话指出最大的问题]

**建议下一步：** [一个具体行动]
```

### 衔接步骤：是否进行深度分析？

输出快速过滤结论后，立即向用户提问（选择题，不等待用户主动询问）：

---

**要不要继续做深度分析？**

- **A)** 是，帮我做全面体检（三要素精度 + 竞品调研 + KANO + 护城河）
- **B)** 不用了，简短结论就够了

---

根据用户选择：

- **选 B（否）** → 流程结束。快速过滤结论即为最终报告，不再追问。
- **选 A（是）** → **自动进入 true-needs-deep 流程**，无需用户重新描述产品想法。直接从 deep skill 的第一步（三要素精度检验）开始执行，将 filter 阶段收集到的信息带入后续分析。

## 红旗词

需求描述中出现以下词语，大概率是想象出来的：

> "应该" · "显然" · "大家都" · "逻辑上说得通" · "用户应该会需要"

遇到这些词时，在评估中明确指出"检测到红旗词，该判断可能是推断而非观察"。

## 常见合理化借口（供参考）

| 说法 | 实际问题 |
|------|--------|
| "我了解我的用户" | 了解 ≠ 观察。有具体行为证据吗？ |
| "竞争对手都在做" | 他们可能也做错了。看用户留存数据。 |
| "用户说他们需要这个" | 用户说想要 ≠ 真的会用。看行为。 |
| "逻辑上说得通" | 想象中的需求逻辑上永远说得通，这正是陷阱所在。 |

## 与其他skill的关系

| 阶段 | Skill | 作用 |
|------|-------|------|
| **快速判断** | true-needs-filter（本skill） | 30秒快速判断 |
| 深度分析 | true-needs-deep | KANO+价值护城河全面体检 |

**两个skill自动衔接：** filter 跑完后会问用户是否深度分析。选"是"则自动进入 deep skill，选"否"则输出简短报告结束。用户无需重新描述产品想法，全程选择题交互。
